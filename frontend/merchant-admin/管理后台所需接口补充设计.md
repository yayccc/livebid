# 商家管理后台所需接口补充设计

本文档记录 `frontend/merchant-admin` 在实现商品管理、竞拍管理和工作台首页时发现的后端 HTTP 接口缺口。当前前端已对这些缺口做降级展示，后端可按本文档逐步补齐。

## 一、商品接口补充

### 1. 商品响应补充 status 字段

当前 `goods-service` 的 proto 和 GORM model 已有 `status` 字段，但 `api-gateway` 的商品 HTTP 响应未返回该字段，导致商家后台无法准确展示商品“上架/下架”状态。

建议调整所有商品响应对象：

```json
{
  "id": 100000000001,
  "shop_id": 10001,
  "title": "高冰翡翠手镯",
  "cover_url": "https://example.com/image.jpg",
  "description": "高冰种翡翠手镯，直播专拍",
  "status": 1,
  "created_at": "2026-05-24 12:00:00",
  "updated_at": "2026-05-24 12:30:00"
}
```

影响接口：

- `GET /api/goods/:id`
- `GET /api/goods`
- `GET /api/goods/shop/list`
- `POST /api/goods`
- `PUT /api/goods/:id`
- `POST /api/goods/batch`

## 二、竞拍接口补充

### 1. 商家竞拍列表返回商品展示字段

当前 `GET /api/auctions/shop` 只返回 `goods_id`，前端需要再调用 `POST /api/goods/batch` 拼接商品标题和封面。建议后端提供聚合字段，减少页面首屏请求数。

建议响应列表项：

```json
{
  "id": 200000000001,
  "goods_id": 100000000001,
  "shop_id": 10001,
  "goods_title": "高冰翡翠手镯",
  "goods_cover_url": "https://example.com/image.jpg",
  "start_price": 10000,
  "bid_increment": 1000,
  "seal_price": 100000,
  "current_price": 18000,
  "bid_count": 8,
  "status": 1,
  "start_time": "2026-05-24 20:00:00",
  "end_time": "2026-05-24 21:00:00"
}
```

建议接口：

```text
GET /api/merchant/auctions
```

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| page | int | 否 | 页码，默认 1 |
| page_size | int | 否 | 每页数量，默认 10 |
| status | int | 否 | 竞拍状态 |
| keyword | string | 否 | 商品标题关键词 |

### 2. 竞拍详情返回运行态倒计时字段

商家后台右侧详情需要展示当前倒计时。当前 HTTP 详情接口未返回 Redis 运行态中的 `expire_at/server_time`，前端只能展示结束时间，无法精确展示竞拍倒计时。

建议新增或扩展：

```text
GET /api/auctions/:id/runtime
```

响应示例：

```json
{
  "auction_id": 200000000001,
  "status": 1,
  "current_price": 18000,
  "bid_count": 8,
  "winner_user_id": 30001,
  "server_time": "2026-05-24 20:15:00",
  "expire_at": "2026-05-24 20:15:14",
  "version": 8
}
```

## 三、工作台统计接口

当前工作台统计由前端基于第一页列表估算，无法保证准确。建议提供商家首页聚合接口。

建议接口：

```text
GET /api/merchant/dashboard/summary
```

响应示例：

```json
{
  "goods_total": 128,
  "goods_on_sale": 86,
  "goods_off_sale": 42,
  "auction_total": 36,
  "auction_running": 6,
  "auction_pending": 12,
  "auction_deal": 14,
  "auction_failed": 3,
  "auction_cancelled": 1,
  "today_deal_amount": 8642000,
  "today_bid_count": 238
}
```

说明：

- 金额单位继续沿用后端现有约定：分。
- 商家身份从 JWT 注入，不允许客户端传 `shop_id`。

## 四、直播管理后续接口建议

直播管理当前仅保留占位页。后续如果要实现商家侧直播间管理，建议确认 `GET /api/live/rooms` 是否默认只返回当前商铺直播间；若不是，建议新增商家视角接口：

```text
GET /api/merchant/live/rooms
```

列表项建议包含：

```json
{
  "id": 700000000001,
  "shop_id": 10001,
  "title": "翡翠专场直播",
  "cover": "https://example.com/live-cover.jpg",
  "status": 1,
  "stream_key": "live_700000000001",
  "started_at": "2026-05-24 20:00:00",
  "ended_at": ""
}
```
