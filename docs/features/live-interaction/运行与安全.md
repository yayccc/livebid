# 直播互动运行与安全

> Status: proposed
> Authority: 本文负责跨 interaction、AI、网关的开关、降级、最终安全边界和端到端 SLO。
> Non-authority: 模型内容策略与离线评测见 ai-service `安全与评测.md`。
> Updated-at: 2026-07-17 +08:00

## 一、P0 安全开关

首版必须具备服务端配置或动态配置能力，不等待商家控制台 UI：

| 开关 | 执行位置 | 失败默认值 |
| --- | --- | --- |
| 全局用户互动开关 | interaction-service | 关闭写入 |
| 房间 `chat_enabled` | live-service + interaction-service | 不明确时拒绝写入 |
| AI 全局输入/输出开关 | interaction-service、ai-service | 关闭 AI |
| shop/room AI allowlist | interaction-service、ai-service | 不在名单不启用 |
| 每场次 AI 冷却 | ai-service | 不生成 |
| 每房间每分钟 AI 硬上限 | interaction-service | 拒绝 AI 回写 |
| 紧急阻断词/输出长度 | interaction-service | 拒绝发布 |

interaction-service 是最终防线：即使 ai-service 配置失效，也必须拒绝被关闭、过期、超限或场次不匹配的 AI 消息。

## 二、降级顺序

1. 模型或知识依赖异常：停止 AI 输出，真人互动不受影响。
2. AI 输入 Pub/Sub 异常：丢弃 AI 观察事件，真人互动继续。
3. live-service 查询异常：用户新写入 fail closed；已有 WS 连接可以继续接收房间广播。
4. interaction-service 或 Redis 写入异常：网关返回不可用，不得本地生成消息或先广播。
5. 房间广播异常：返回结果未知/不可用并允许原幂等键短重试；不得切换为网关第二写入口。

RocketMQ 不作为实时故障切换链路，避免双链路造成重复、乱序和双真相。

## 三、AI 竞态

- AI 生成前和 interaction 回写时都校验 `live_session_id` 与过期时间。
- 回写校验的线性化语义是“请求提交前最后一次 live-service 校验时仍为当前场次”；与 `EndLive` 同时发生的在途消息可能成为该场次最后一条消息，事件携带原 session 供客户端识别。
- 主播关闭 AI、切换场次或命中硬上限后，新回写必须拒绝；AI 收到对应错误后不得换新 `decision_id` 绕过。
- `decision_id` 只处理同一次发布重试；并发实例产生相似回答由 session inflight、意图预留和冷却处理。

## 四、数据与隐私

- 模型只接收回答所需的白名单字段，不传用户联系方式、收货信息、竞拍胜者 ID、内部备注或完整业务 Proto。
- 日志不记录未来接入的服务凭证、完整 Prompt、原始用户隐私或未脱敏 Tool 响应。
- P0 决策审计保存 ID、路由、模型版本、延迟、动作、拒绝原因和脱敏来源摘要；保留期配置化。
- 公开消息不携带内部 `source_refs`、模型思维过程或安全规则详情。

## 五、P0 SLO 与指标

目标以服务端观测为准，首次压测后可调整数值但不改变语义：

| 指标 | P0 目标 |
| --- | --- |
| 用户发布 gRPC P95 | ≤ 100 ms，不含客户端网络 |
| 接纳到房间 Pub/Sub P95 | ≤ 50 ms |
| AI 候选接纳到回写 P95 | ≤ 3 s；超时直接放弃 |
| interaction 发布可用性 | ≥ 99.9%（目标） |
| AI 输入丢失率 | 观测但不设可靠性承诺 |
| AI 公开消息硬上限 | 配置化，且 interaction 独立执行 |

必须按 `room_id`、`live_session_id`、错误类别和阶段记录：写入量、幂等命中、频控、Lua 延迟、广播失败、AI 输入丢弃、候选淘汰、模型超时、场次失配和安全拒绝。指标标签不得使用高基数的完整 message/trace ID。

## 六、告警

P0 至少覆盖：

- interaction gRPC 错误率或 Redis 延迟持续超阈值。
- 房间发布失败突增或网关订阅恢复失败。
- AI 输出速率超过硬上限、拒绝率突增或同场次重复回答异常。
- Tool 动态事实读取失败、模型超时和安全阻断突增。
- live-session 失配率上升，提示 live 状态传播或迟到任务问题。
