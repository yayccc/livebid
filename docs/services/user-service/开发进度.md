### 阻塞点

- 无编码阻塞。

### 设计变更

- 登录由 `user-service` 直接签发 JWT，而不是返回 opaque token。
- `GetUser(id)` 允许内部服务按任意用户 ID 查询公开资料。
- 当前用户资料和地址接口统一以 metadata `livebid-auth-subject` 作为身份来源。
- 修改地址采用部分更新语义。
- 用户主表名保持为 `user`。
- `phone`、`email` 非必填时允许为空，唯一性只对非空值做仓储层校验。
