# 竞拍服务

### 需求分析

针对直播竞拍平台中的实时竞拍业务需求，构建独立的竞拍管理与出价服务体系，实现竞拍从创建配置、绑定直播间、开始、用户出价到成交或流拍的完整业务闭环，并为直播间实时展示、订单生成和商家管理端提供核心竞拍能力支撑。

### 核心功能

1. 实现竞拍活动创建与规则配置功能，支持绑定直播间，并设置起拍价、加价幅度、封顶价、开始时间和结束时间等竞拍规则。

2. 提供竞拍状态管理能力，支持待开始、竞拍中、已成交、已流拍、已取消等状态流转，不引入竞拍上架或下架状态。

3. 实现用户出价功能，对竞拍状态、出价金额、加价幅度、封顶价和连续出价限制进行校验，保证竞拍过程合法有效。封顶价为最高合法出价，超过封顶价的出价直接拒绝。

4. 记录竞拍出价明细，维护当前最高价、出价次数、获胜用户和成交金额等竞拍运行时数据。每次成功出价后刷新 15 秒成交倒计时，15 秒内无人再次成功出价则自动成交。

5. 通过消息事件通知机制，将竞拍价格变化、成交结果等信息推送给 WebSocket 服务、直播服务和订单服务。竞拍事件必须携带直播间 ID，便于 WebSocket 服务按直播间广播。
